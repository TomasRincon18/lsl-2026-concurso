# URAB IA — Presentación de Ciencia de Datos (LSL 2026)

Demostración interactiva en Streamlit de la solución de IA para el macroproceso
de atención y trámite de PQRSD de la Defensoría del Pueblo (URAB).

## Ejecutar localmente

```bash
pip install -r requirements.txt
streamlit run script_simulador/presentacion_ciencia_datos.py
```

## Desplegar en Streamlit Community Cloud

1. Sube este repositorio a GitHub.
2. Entra a https://share.streamlit.io y conéctate con GitHub.
3. Clic en **"New app"** → selecciona el repositorio, la rama `main` y como
   *Main file path*: `script_simulador/presentacion_ciencia_datos.py`.
4. Clic en **Deploy**. Obtendrás un link público `https://<tu-app>.streamlit.app`.
